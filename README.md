# six-wins-goal-coach

一个独立的 Codex skill：把目标拆成六次可控、可验证的小胜利，并在每轮结束后根据证据复盘。适用于推进项目、学习、健身和习惯养成。

## 安装

```bash
git clone https://github.com/Jasonfu828/six-wins-goal-coach.git ~/.codex/skills/six-wins-goal-coach
```

重启 Codex 或开始新对话后，可说“启动 6 Wins”“打卡 6 Wins”或“复盘 6 Wins”。

## 文件

- `SKILL.md`：完整使用说明与边界。
- `templates/progress.md`：可复制到新对话的进度快照。

`6` 是管理节奏，不是经科学证实的成功阈值；可按任务调整。
